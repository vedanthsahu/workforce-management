# Configuration: Business Rules

## Overview

Each organisation sets its own policies on the **Configuration** screen. Changes take effect for all users on their next action, without any software change or deployment.

## Available settings

| Group | Setting | Effect |
|---|---|---|
| Booking | Employee booking window (days ahead) | How far into the future employees may book |
| Booking | Visitor booking window (days ahead) | How far ahead visits and visitor desks may be planned |
| Floor plans | Notice period (days) | Minimum notice before a planned layout change |
| Floor plans | Visibility of draft, archived and deleted layouts (days) | How long non-live layouts stay listed for administrators |
| Blocked seats | Maximum days ahead for a block | How far ahead desks may be blocked |
| Blocked seats | Upcoming, expiring-soon and expired windows | How blocks are grouped on the overview screen |
| Activity | Number of activity entries | Length of the dashboard activity feed |
| Assistant | Show the chatbot to employees | Turns the assistant on or off for employees |

## How settings work

- Every setting has a sensible default; an organisation only overrides what it needs.
- Values are validated (for example, a booking window must be at least one day).
- Booking screens read the current settings, so the date picker always matches the policy.

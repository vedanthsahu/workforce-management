# Glossary

| Term | Meaning |
|---|---|
| Amenity | A feature of a desk, such as a docking station or standing desk |
| Audit log | The record of who did what, when, and with what outcome |
| Blocked seat | A desk taken out of use for a period |
| Booking | One desk reserved for one person or visitor on one day |
| Booking window | How many days ahead bookings may be made; set per organisation |
| Business rule | An organisation-level setting that shapes how SeatBook behaves |
| Delegated booking | A booking made by a facilitator or administrator for someone else |
| Desk / seat | A bookable place on a floor plan |
| Facilitator | A coordinator who books for colleagues and visitors |
| Floor layout / floor plan | A version of a floor's drawing, with its desks |
| Front office | Reception staff who record visitor arrivals and departures |
| Host | The employee a visitor comes to see |
| Organisation / tenant | A customer organisation using SeatBook, fully separated from others |
| Site / office | The top level of the location hierarchy |
| Single sign-on (SSO) | Signing in with the corporate Microsoft account |
| Tenant admin | An organisation's SeatBook administrator |
| Visit | A visitor's planned presence on a given day, with host and optional desk |
| Visitor / guest | A person without a SeatBook account who is registered for a visit |
